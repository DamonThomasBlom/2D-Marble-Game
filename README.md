# 🌀 Marble Clash 2D

A chaotic, colorful 2D marble simulation game where marbles battle for territory, power, and glory.  
Inspired by Mikan’s territory war videos — but with a twist of personality, physics, and player interaction!

[![Watch the Demo](https://www.youtube.com/watch?v=TyBNOLfH2rI&t/maxresdefault.jpg)](https://www.youtube.com/watch?v=TyBNOLfH2rI&t)

---

## 🎮 Gameplay Overview

- 🟢 Spawn your marbles into a live simulation
- ⚔️ Watch them push, shove, and collide for dominance
- 🎨 Each marble belongs to a faction and contributes to territorial control
- 🧠 Includes a territory control mechanic and plinko like mini-game

---

## ✨ Features

- 🧲 Physics-based marble movement and collisions
- 🌈 Color-coded factions and real-time visual feedback
- 🧠 Mini-games that influence the main battle
- 🔁 Endless simulation mode with random or scripted setups
- 🎥 Perfect for video content creation or chill observation

---

## 🛠️ Tech Stack

- Unity 2D (URP)
- DOTween (for animations)
- Built for Windows
